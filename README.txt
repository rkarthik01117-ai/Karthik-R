CRICKSTATS — Offline Cricket Player Performance Tracker

HOW TO RUN
1. Extract this ZIP file to a folder.
2. Open CRICKSTATS.html with Chrome, Edge, or another modern browser.
3. Click Players → Register Player.
4. Click Add Match to enter a player's performance.
5. Use Dashboard and Reports & Stats to view summaries.
6. Use Export CSV to download match records.

NOTES
- This is a standalone offline HTML/CSS/JavaScript demo based on the supplied CRICKSTATS project document.
- Player and match records are stored in the browser's Local Storage on the device/browser where you use it.
- No installation, server, or internet connection is needed after the file is saved.
- Do not clear browser site data if you need to preserve records. Export CSV regularly as a backup.
- The supplied ZIP contained a project write-up, not a Salesforce source-code project. This demo implements similar core tracking features locally; it is not a Salesforce deployment package and does not include Salesforce login, cloud syncing, or Salesforce Flows.
